# Portfolio case study questions

Answer inline under each question (one line is fine — "don't know" or "skip" is fine too).
When you're done, tell Claude and the answers get turned into expanded case studies.

**Why these questions:** when someone asks ChatGPT/Gemini/Claude "best web designer in Merthyr" or
"compare NC Digital with X", the model is looking for *specific, checkable facts* — dates, numbers,
platforms, page counts, ranking positions, named services, client quotes. Vague copy ("professional
presence", "steady flow of enquiries") gets skipped. Every answer below feeds a fact the AI can repeat.
